# prive-public

The two public documents of PRIVÉ, served by GitHub Pages at https://legal.prive.talk:

- `terms/` : Terms of Use
- `privacy/` : Privacy Policy

Plain HTML and one stylesheet; nothing is built and nothing is fetched from a third party. The app links to `/terms/` and `/privacy/`, so those two paths never change. When a document changes, change the date at its top.
